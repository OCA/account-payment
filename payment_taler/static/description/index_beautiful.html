Taler-Odoo Payment System

Integrate GNU Taler payments directly into your Odoo eCommerce and invoicing workflows.

Why use Taler payments in Odoo?

Native Odoo Integration

Accept Taler payments directly inside your Odoo install using existing Odoo modules

  • eCommerce
  • Invoices
  • Ticket sales
  • Online payments
  • And more...

Privacy Friendly

GNU Taler protects customer privacy while still allowing merchants to comply to taxability and auditing.

Free software

Both GNU Taler and the Taler-Odoo Payment System add-on are FOSS

Documentation

You can find an extensive documentation of this module on the main repository.

Easy Install

Install the module like any other Odoo add-on and configure your Taler payment provider.
